Định nghĩa

1. Tận tâm, chu đáo, không quản ngại khó khăn để giúp đỡ hoặc bày tỏ tình cảm.

2. Lễ tiết long trọng, thái độ tôn trọng và quan tâm sâu sắc.

Mẹo học chữ

Mỗi chữ Hán đều mang một câu chuyện triết học. Ví dụ: Chữ Ân (慇) gồm bộ Tâm ở dưới, thể hiện tình cảm xuất phát từ đáy lòng.
